# Crystal Play kz

Статическая главная страница видеоплатформы Crystal Play kz для midterm-проекта по Web Technologies. Композиция основана на предоставленном Figma-скелете: верхняя панель со значком мессенджера, колонка коротких видео Shorts слева и три столбца обычных видео на компьютере.

## Как открыть

Откройте `index.html` в браузере. Установка пакетов и сборка не нужны. Bootstrap, фотографии, CSS и favicon сохранены локально, поэтому страница работает без интернета.

## Что реализовано

- Только HTML5 и CSS, без JavaScript и Bootstrap JS.
- Семантические `header`, `nav`, `aside`, `main`, `section`, `article`, `footer`, заголовки, списки и изображения с `alt`.
- 12 карточек обычных видео, 3 вертикальных превью Shorts в формате 9:16, макет формы поиска и значок мессенджера вместо загрузки видео.
- Shorts показывают длительность, название, автора, просмотры, отметки «Нравится» и комментарии. Это статические превью, без воспроизведения и переходов.
- Bootstrap 5.3.8: сетка `row`, `col`, `row-cols-*`; классы контейнеров, форм, отступов, Flexbox, выравнивания и скрытых подписей.
- CSS Grid для основной композиции; Flexbox для шапки и метаданных; `position: relative/absolute` для надписей и длительности на превью.
- Адаптивность: три столбца обычных видео от 992px, два от 768px, один ниже 768px. Дополнительные media queries адаптируют шапку, Shorts и размеры текста. На телефоне Shorts расположены после основной ленты; значок мессенджера остаётся видимым.
- Единая палитра, локальные фотографии, SVG-иконки, состояния фокуса ссылок и доступные подписи элементов.

## Текущий этап и требования задания

По просьбе пользователя готовится только интерфейс главной страницы. Поиск, категории, мессенджер, уведомления, профиль, Shorts и карточки видео пока не выполняют действий. Форма поиска отключена, чтобы её нельзя было отправить; многоточия и фильтры — декоративные элементы. Блок расписания эфиров удалён по просьбе пользователя.

Пользователь описал будущий проект из пяти страниц: главная, мессенджер, лента Shorts, просмотр обычного видео с Shorts слева и просмотр отдельного Shorts. Пока реализована только главная. Существующие подписи навигации остаются статическими обозначениями; новые страницы и ссылки не добавлены. Окончательную навигацию и остальные страницы нужно сверстать по следующему макету пользователя.

Для полного задания ещё необходимы четыре страницы и работающие переходы, таблица и содержательная форма на подходящих страницах, публикация на GitHub Pages или Netlify и подготовка к защите. Названия каналов и статистика — демонстрационные данные. Наличие одной главной страницы само по себе не обеспечивает 100 баллов: 30 баллов выделено за защиту.

## Структура

```text
index.html                         Главная страница
assets/css/style.css               Авторские стили и media queries
assets/icons/favicon.svg           Значок сайта
assets/images/                     12 локальных фотографий
assets/vendor/bootstrap/           CSS Bootstrap и лицензия MIT
```

Основные блоки CSS разделены комментариями для удобства объяснения на защите. HTML не требует сервера; для будущей публикации главная страница уже называется `index.html`.
