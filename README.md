# Crystal Play kz

Учебный видеосервис. Endterm продолжает существующий сайт на HTML, CSS и Bootstrap.

## Предпросмотр видео

На главной странице подключены пять предпросмотров: Месси в Барселоне, Costa Rica,
Месси в Аргентине, «Бэтмен», Роналду и Месси.

- Наведи мышь на карточку на 350 мс: начнётся предпросмотр без звука.
- Уведи курсор: видео остановится, снова появится обложка.
- Кнопка «Предпросмотр» запускает видео на телефоне и с клавиатуры; повторное
  нажатие останавливает его. Для клавиатуры: Tab, затем Enter или пробел.
- Escape, переход в другую вкладку и прокрутка карточки за пределы экрана
  останавливают предпросмотр. Одновременно воспроизводится одна карточка.
- Короткие ролики до 10 секунд повторяются целиком. В более длинных роликах
  чередуются три фрагмента по 3 секунды.
- При настройке системы «уменьшение движения» или экономии трафика браузера
  автоматический запуск отключён; кнопка остаётся доступной.

Видео загружаются только после запуска предпросмотра. Четыре подготовленных MP4
находятся в `assets/videos/`; Costa Rica использует существующий `videos/vid1.mp4`.
Логика находится в `assets/js/video-previews.js`.

## Как проверить

Запусти `index.html` через Live Server в редакторе. Это даёт главной странице
и мессенджеру общее хранилище сообщений. При открытии через `file://` поведение
хранилища между страницами зависит от браузера. Проверь все пять карточек, быстрое перемещение между ними,
кнопку запуска/остановки, Escape и возврат из другой вкладки. Ссылка на страницу
Costa Rica должна открываться как прежде.

Для программной проверки логики предпросмотров (нужен Node.js):

```sh
node --test tests/*.test.cjs
```

Эти проверки используют имитацию DOM и медиаплеера. Отображение и декодирование
видеофайлов следует дополнительно проверить в браузере.

## Поиск и категории

Поиск работает при вводе и при отправке формы: по названию, каналу и ключевым
словам, включая русские названия «Коста-Рика» и «Бэтмен». Категории работают
совместно с поиском. Для пустого результата есть кнопка сброса фильтров.
В текущем каталоге нет челленджей, поэтому эта категория показывает пустой результат.
Поиск в шапке мессенджера открывает результаты на главной.

Проверка: введи «Месси» (3 видео), выбери «Природа» (0 видео), сбрось фильтры.
Категория «Футбол» показывает 3 видео, «Кино» — 1, «4K HDR» — 1.

## Смотреть позже

Под каждой карточкой есть кнопка добавления и удаления из списка. Кнопка
«Смотреть позже» над лентой переключает режим отображения сохранённых видео;
повторное нажатие возвращает общую ленту. Поиск и категории действуют и в этом режиме.
Список сохраняется в `localStorage` и восстанавливается после перезагрузки.

Проверка: сохрани два видео, открой список, обнови страницу, снова открой список,
удали одно видео, затем последнее. Проверь счётчик и сообщение о пустом списке.

## Отправка видео в чат

Нажми «Отправить в чат», выбери Алию, Данияра или Марата и нажми «Отправить».
Уведомление содержит ссылку на выбранную переписку. Карточка видео сохраняется
в истории вместе с обычными сообщениями; открытая вкладка мессенджера получает
обновления через событие `storage`. Старые текстовые сообщения сохраняются.

У Costa Rica ссылка ведёт на существующую страницу просмотра. Для остальных
четырёх видео открывается предоставленный MP4-фрагмент. Реальная отправка
другим пользователям не выполняется: переписка демонстрационная, в этом браузере.

Проверка: отправь разные видео двум контактам, открой их чаты и обнови страницу.
После отправки видео добавь обычное текстовое сообщение — оба должны остаться
в истории. Без выбора контакта форма показывает ошибку.

Общий каталог, контакты и работа с хранилищем находятся в `assets/js/app-data.js`.
Логика ленты — в `assets/js/feed.js`, переписки — в `messenger/messenger.js`.
